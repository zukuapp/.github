이 저장소는 **zukuapp 조직의 얼굴과 문**입니다.

GitHub가 [github.com/zukuapp](https://github.com/zukuapp) 홈에 그리는 카드는 `profile/README.md` 입니다.  
루트 README는 그 프로필을 고치고, 커뮤니티 파일을 보태고, 파동을 이어가는 사람들을 위한 지도입니다.

## 이 레포에서 만질 수 있는 것

| 경로 | 역할 | 누가 열면 보이나 |
|---|---|---|
| [`profile/README.md`](profile/README.md) | 조직 홈 본문 | 누구나, 조직 페이지 |
| [`profile/assets/`](profile/assets) | 히어로 · 표면 카드 · 작업대 칩 | 프로필에 임베드 |
| 이 파일 | 커뮤니티 파일 저장소 안내 | 이 레포를 연 사람 |

브랜드 표기: **ZUKU (즈쿠)** · 회사 **Tresillo (트레실로)** · 레포 접두사 `zuku-`.  
“시즈쿠”는 쓰지 않습니다.

## 프로필을 직접 만져 보세요

조직 홈은 표가 아니라 **고르는 화면**이어야 합니다.

1. [조직 홈](https://github.com/zukuapp)에서 표면 카드를 눌러 호스트로 이동합니다.
2. **어떻게 들어오시겠어요?** 를 열어 플레이어 · 크리에이터 · 게임 메이커 · 기여자 경로를 고릅니다.
3. 카피나 카드를 고치고 싶으면 `profile/` 을 수정한 뒤 이 레포에 PR을 엽니다.

<details>
<summary><strong>에셋 다시 그리기</strong> — 카드·칩·히어로</summary>
<br/>

표면 색과 문구는 `profile/assets/_gen_cards.py` 에 모여 있습니다.

```bash
python profile/assets/_gen_cards.py
```

히어로의 파동(ripple)은 Z 마크가 수면에 떨어진 자리입니다. 번호 매긴 01/02/03 목록으로 되돌리지 마세요.

</details>
