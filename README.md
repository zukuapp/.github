이 저장소는 **zukuapp** 조직의 얼굴입니다.

GitHub가 [github.com/zukuapp](https://github.com/zukuapp)에 보여주는 소개는 [`profile/README.md`](profile/README.md) 입니다.  
**ZUKU(즈쿠)** 는 **Tresillo(트레실로)** 가 만드는 창작 미디어 플랫폼입니다.

## 구성

| 경로 | 역할 |
|---|---|
| [`profile/README.md`](profile/README.md) | 조직 홈에 보이는 회사·제품 소개 |
| [`profile/assets/`](profile/assets) | 히어로, 제품 카드, 공개 도구 칩 |

브랜드 표기: **ZUKU (즈쿠)** · 회사 **Tresillo (트레실로)** · 레포 접두사 `zuku-`.  
“시즈쿠”는 쓰지 않습니다.

문의: [contact@crevision.kr](mailto:contact@crevision.kr)

## 소개를 고치려면

1. [조직 홈](https://github.com/zukuapp)에서 제품 카드를 눌러 서비스로 이동합니다.
2. **어떻게 시작하나요** 에서 플레이 · 창작 · 게임 · 오픈소스 · 회사 경로를 고릅니다.
3. 문구를 바꾸려면 `profile/README.md` 를 수정한 뒤 이 저장소에 변경을 올립니다.

<details>
<summary><strong>카드 그림을 다시 그리려면</strong></summary>
<br/>

제품 색과 짧은 설명은 `profile/assets/_gen_cards.py` 에 있습니다.

```bash
python profile/assets/_gen_cards.py
```

히어로의 파동은 Z 마크가 수면에 떨어진 자리입니다. 제품을 01·02·03 번호 목록으로 되돌리지 마세요.

</details>
