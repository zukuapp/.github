# 브랜드·타이포그래피 / Brand and typography

ZUKU 문서는 승인된 ZUKU 로고를 사용합니다. 회사명 Trecillo와 기존 상류 저작권·라이선스는 보존합니다.

[한국어·영어 로고 사용 안내](branding/README.md)는 원본 파일, 밝은/어두운 배경 선택과 SHA-256을 제공합니다.

ZUKU documentation uses the approved ZUKU logo. Preserve the legal operator name Trecillo and existing upstream notices and licenses. See the [Korean and English logo guide](branding/README.md) for original files, theme selection, and SHA-256 checksums.

## 서체와 색상 / Typography and colors

사이트 글꼴은 한글 Pretendard, 영문 Inter이고, 문서 사이트는 Wanted Sans를 사용합니다.

Sites use Pretendard for Korean and Inter for Latin text; the documentation site uses Wanted Sans.

| Product | Color |
| --- | --- |
| SWIPE | `#FFD600` |
| JUMP | `#EC008C` |
| HYPE | `#00BCF2` |

이 색상은 제품 구분에만 사용하고 로고에는 적용하지 않습니다. / Use these colors to distinguish products, not to recolor the logo.
