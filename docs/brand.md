# 브랜드·타이포그래피 / Brand and typography

ZUKU 문서는 승인된 ZUKU 로고를 사용합니다. 회사명 **Trecillo**와 기존 상류 저작권·라이선스는 보존합니다.

[한국어·영어 로고 사용 안내](branding/README.md)에서 원본 파일, 밝은/어두운 배경 선택과 SHA-256을 확인하세요. 공식 슬로건은 **ZUKU - 내가 불러 일으키는 새로운 창작.**입니다.

ZUKU documentation uses the approved ZUKU logo. Preserve the legal operator name Trecillo and existing upstream notices and licenses. See the [Korean and English logo guide](branding/README.md) for original files, theme selection, and SHA-256 checksums. The official slogan above stays unchanged in every locale.

## 서체와 색상 / Typography and colors

GitHub README의 본문 글꼴은 GitHub가 제공합니다. 제목·설명·링크는 검색과 접근성을 위해 텍스트로 유지합니다. 기존 사이트의 한글 Pretendard와 영문 Inter를 유지하며 문서 사이트의 Wanted Sans는 해당 사이트의 글꼴 라이선스를 따릅니다. 새 배너나 벡터 로고를 재생성하지 않습니다.

GitHub supplies README body fonts. Keep headings, descriptions, and links as text. Preserve the existing site fonts and their licenses. Do not regenerate banners or redraw the logo.
